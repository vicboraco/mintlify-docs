Your Piixan AI workspace settings give you full control over how the platform behaves for you and your team. From choosing a default AI model to setting your preferred timezone, every option here shapes how Piixan AI fits into your day-to-day work.

## Accessing Settings

Navigate to [https://app.piixan.ai/settings](https://app.piixan.ai/settings) from any page in the dashboard. You can also click your workspace avatar in the top-right corner and select **Settings** from the dropdown menu.

## General Settings

The **General** tab lets you configure the core identity and behavior of your workspace.

<CardGroup cols={2}>

### Default AI Model

When you create a new workflow or make an API call without specifying a `model` parameter, Piixan AI falls back to whatever model you've set as your workspace default. Choose from:

| Model | Best For | Speed |
|---|---|---|
| `piixan-1` | General-purpose tasks, everyday automation | Fast |
| `piixan-1-turbo` | High-volume tasks requiring fast throughput | Fastest |
| `piixan-pro` | Complex reasoning, long-context documents | Accurate |

To update the default, go to **Settings → General → Default AI Model**, select your preferred model, and click **Save Changes**.

## API Settings

The **API** tab centralises settings that affect how your API keys and requests are handled.

### Managing API Keys

API keys authenticate every request you make to the Piixan AI API. You can create, rotate, and revoke keys from **Settings → API Keys**, or visit [https://app.piixan.ai/settings/api-keys](https://app.piixan.ai/settings/api-keys) directly. For detailed setup instructions, see the [Authentication guide](/getting-started/authentication).

### Request Timeout

Control how long Piixan AI waits before cancelling a request that hasn't returned a response.

| Setting | Value |
|---|---|
| Default timeout | 30 seconds |
| Maximum timeout | 120 seconds |

Increase this value if you regularly work with large documents or complex reasoning tasks that take longer to process. Set it in **Settings → API → Request Timeout**.

### Default Max Tokens

You can configure a workspace-level `max_tokens` cap that applies to every completion request unless the request itself specifies a different value. This helps you control credit consumption and prevents runaway token usage from a misconfigured workflow.

## Data & Privacy

The **Privacy** tab gives you visibility and control over how Piixan AI stores and uses data generated by your requests.

### Data Retention Policy

Piixan AI retains request logs — including prompts, completion outputs, and associated metadata — for **30 days** by default. After 30 days, logs are automatically and permanently deleted. You cannot recover logs once they have been purged.

### Disabling Request Logging

If your use case requires stricter data handling, you can disable request logging entirely under **Settings → Privacy → Request Logging**. Toggle the switch to **Off** and confirm your choice.

<Warning>
  Disabling request logging is permanent for any requests made while the setting is off — those logs are never written to disk. If you need to debug a failed request or replay a workflow, you will have no log data to reference. Only disable logging if your compliance requirements explicitly demand it, and ensure your own application captures the data you need for debugging.
</Warning>

### Data Export

You can export all stored request logs at any time before they are purged. Navigate to **Settings → Privacy → Export Data**, select a date range, and click **Export**. Piixan AI will email you a download link within a few minutes. Exports are delivered as compressed JSON files.
