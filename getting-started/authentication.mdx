Piixan AI uses API keys to authenticate every request to the REST API. You generate keys from your dashboard and pass them in the `Authorization: Bearer` header — there are no sessions or cookies to manage. Keep your keys secret; anyone who holds a key can act on behalf of your account up to that key's permission scope.

## Creating an API Key

<Steps>
  <Step title="Open the API Keys page">
    Sign in to your dashboard and navigate to [https://app.piixan.ai/settings/api-keys](https://app.piixan.ai/settings/api-keys). This page lists all active keys associated with your account along with their scopes and creation dates.
  </Step>

  <Step title="Generate a new key">
    Click **Create New Key**. Enter a descriptive name — for example, `production-backend` or `ci-pipeline` — and an optional description so you can identify the key's purpose later. Choose the appropriate scope (see the note below) and click **Create**.
  </Step>

  <Step title="Copy your key">
    Your new API key is displayed exactly once immediately after creation. Copy it now and store it somewhere safe, such as a password manager or a secrets vault.

    <Warning>
      Piixan AI never shows you the full key again after you leave this screen. If you lose it, you must revoke the key and create a new one. Do not share keys in chat, email, or source control.
    </Warning>
  </Step>
</Steps>

## Using Your API Key

Pass your API key as a Bearer token in the `Authorization` header of every HTTP request. The examples below show how to authenticate a basic completion request across common environments.

<CodeGroup>

```bash curl
curl --request POST \
  --url https://app.piixan.ai/v1/completions \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "prompt": "Summarize the benefits of workflow automation.",
    "max_tokens": 256
  }'
```

```python Python
import os
import requests

api_key = os.environ["PIIXAN_API_KEY"]

response = requests.post(
    "https://app.piixan.ai/v1/completions",
    headers={
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "Summarize the benefits of workflow automation.",
        "max_tokens": 256,
    },
)

data = response.json()
print(data["choices"][0]["text"])
```

```javascript JavaScript / Node.js
const apiKey = process.env.PIIXAN_API_KEY;

const response = await fetch("https://app.piixan.ai/v1/completions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    prompt: "Summarize the benefits of workflow automation.",
    max_tokens: 256,
  }),
});

const data = await response.json();
console.log(data.choices[0].text);
```

</CodeGroup>

## API Key Best Practices

Following a few simple rules dramatically reduces the risk of a key being leaked or misused.

- **Store keys in environment variables** — Read your key from `process.env` or `os.environ` at runtime rather than writing the value directly into your code.
- **Never commit keys to source control** — Add `.env` files and secrets files to your `.gitignore` before your first commit.
- **Create one key per environment or application** — Use separate keys for local development, staging, and production. If one key is compromised, you can revoke it without disrupting other systems.
- **Rotate keys periodically** — Generate a replacement key, update your environment, verify everything works, then revoke the old key. Aim to rotate production keys at least once per quarter.

<Tip>
  Use a `.env` file at the root of your project and load it with a library like [`python-dotenv`](https://pypi.org/project/python-dotenv/) (Python) or [`dotenv`](https://www.npmjs.com/package/dotenv) (Node.js). This keeps secrets out of your codebase while making them available as environment variables during development.
</Tip>

## Revoking API Keys

If a key is compromised, no longer needed, or due for rotation, revoke it immediately to prevent further use.

<Steps>
  <Step title="Open the API Keys page">
    Navigate to [https://app.piixan.ai/settings/api-keys](https://app.piixan.ai/settings/api-keys) and find the key you want to remove.
  </Step>

  <Step title="Revoke the key">
    Click **Revoke** next to the key, then confirm the action in the dialog. The key is invalidated instantly — any requests using it will receive a `401 Unauthorized` response from that point forward.
  </Step>
</Steps>

## Authentication Errors

When a request fails due to an authentication problem, the API returns one of the following HTTP status codes.

| Status Code | Meaning | Common Cause |
|-------------|---------|--------------|
| `401 Unauthorized` | The API key is missing, malformed, or has been revoked. | Forgot to include the `Authorization` header, or the key was rotated/revoked. |
| `403 Forbidden` | The key is valid, but lacks permission for the requested operation. | Using a `read`-scoped key to call a write endpoint, or attempting an admin action with a non-admin key. |

<Note>
  API keys are issued with one of three scopes that limit what they can do. A **read** key can only call `GET` endpoints. A **write** key can call both `GET` and `POST`/`PUT`/`DELETE` endpoints. An **admin** key additionally grants access to account management operations such as managing team members and billing. Always use the least-privileged scope required by your application.
</Note>
