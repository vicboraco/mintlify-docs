---

By the end of this guide you will have a Piixan AI account, a working API key, and a successful AI completion response returned to your terminal. The whole process takes around five minutes and requires no prior setup beyond a browser and either `curl` or Python installed on your machine.

<Steps>
  <Step title="Create Your Account">
    Navigate to [app.piixan.ai/signup](https://app.piixan.ai/signup) and fill in your name, email address, and a secure password. After you submit the form, check your inbox for a verification email and click the confirmation link to activate your account. Once confirmed, you'll land in the Piixan AI dashboard with free trial credits already applied.
  </Step>

  <Step title="Get Your API Key">
    In the dashboard, open **Settings → API Keys** or go directly to [app.piixan.ai/settings/api-keys](https://app.piixan.ai/settings/api-keys). Click **Create New Key**, enter a descriptive label (for example, `my-first-key`), and confirm.

    <Warning>
      Copy your API key immediately and store it somewhere safe — such as a password manager or a `.env` file. Piixan AI displays the full key **only once**. If you lose it, you must revoke the key and generate a new one.
    </Warning>
  </Step>

  <Step title="Make Your First Request">
    Send a `POST` request to `/v1/completions` with your API key in the `Authorization` header. The examples below ask Piixan AI to summarise the benefits of AI automation in three bullet points. Replace `<YOUR_API_KEY>` with the key you copied in the previous step.

    <CodeGroup>
      ```bash curl
      curl --request POST \
        --url https://api.piixan.ai/v1/completions \
        --header "Authorization: Bearer <YOUR_API_KEY>" \
        --header "Content-Type: application/json" \
        --data '{
          "prompt": "Summarize the benefits of AI automation in 3 bullet points.",
          "max_tokens": 200
        }'
      ```

      ```python Python
      import os
      import requests

      api_key = os.environ["PIIXAN_API_KEY"]

      response = requests.post(
          "https://api.piixan.ai/v1/completions",
          headers={
              "Authorization": f"Bearer {api_key}",
              "Content-Type": "application/json",
          },
          json={
              "prompt": "Summarize the benefits of AI automation in 3 bullet points.",
              "max_tokens": 200,
          },
      )

      print(response.json())
      ```
    </CodeGroup>

    A successful response returns a JSON object containing a `choices` array with your AI-generated text:

    ```json
    {
      "id": "cmpl-a1b2c3d4e5",
      "object": "completion",
      "choices": [
        {
          "text": "1. Reduces manual effort by handling repetitive tasks automatically.\n2. Speeds up processes and shortens turnaround times.\n3. Frees your team to focus on higher-value, creative work.",
          "index": 0,
          "finish_reason": "stop"
        }
      ],
      "usage": {
        "prompt_tokens": 14,
        "completion_tokens": 42,
        "total_tokens": 56
      }
    }
    ```
  </Step>

  <Step title="Explore the Dashboard">
    Head back to [app.piixan.ai](https://app.piixan.ai) to explore everything else the platform offers. From the dashboard you can create and run saved workflows, upload files for AI processing, monitor real-time usage and credit balance, manage team members and shared workspaces, and configure webhooks to receive event notifications in your own systems.
  </Step>
</Steps>

<Note>
  Every new Piixan AI account includes free trial credits so you can explore the API and build a proof-of-concept at no cost. Check your remaining balance at any time by calling `GET /v1/usage` or visiting the **Usage** page in your dashboard.
</Note>
