Upload files to use as context in your completions and workflows — giving the AI direct access to your documents, data, and images. Piixan AI supports PDF, DOCX, TXT, CSV, PNG, and JPG files up to 20 MB each.

## Upload a File

Send a file to Piixan AI and receive a file ID you can reference in subsequent API calls.

```
POST https://api.piixan.ai/v1/files/upload
```

<Info>
  This endpoint accepts `multipart/form-data` — not JSON. Make sure your request sets `Content-Type: multipart/form-data` (most HTTP clients handle this automatically when you attach a file).
</Info>

### Request Body

<ParamField body="file" type="file" required>
  The file to upload. Must be one of the supported types: PDF, DOCX, TXT, CSV, PNG, or JPG. Maximum file size is 20 MB.
</ParamField>

<ParamField body="purpose" type="string" default="context">
  Describes how the file will be used. Accepted values:
  - `context` — attach the file's content as background context in a completion or workflow
  - `analysis` — process the file for structured data extraction or analysis tasks
</ParamField>

### Response Body

<ResponseField name="id" type="string">
  The unique file identifier, e.g., `file_abc123`. Store this — you'll use it to reference the file in completions and workflows.
</ResponseField>

<ResponseField name="filename" type="string">
  The original filename as provided during upload.
</ResponseField>

<ResponseField name="size_bytes" type="integer">
  The size of the uploaded file in bytes.
</ResponseField>

<ResponseField name="purpose" type="string">
  The purpose value you specified at upload time.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp for when the file was uploaded.
</ResponseField>

### Example

```bash cURL
curl -X POST https://api.piixan.ai/v1/files/upload \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@/path/to/your/document.pdf" \
  -F "purpose=context"
```

**Example response:**

```json
{
  "id": "file_abc123",
  "filename": "document.pdf",
  "size_bytes": 204800,
  "purpose": "context",
  "created_at": "2024-01-15T09:00:00Z"
}
```

## Retrieve a File

Fetch metadata for a previously uploaded file using its ID.

```
GET https://api.piixan.ai/v1/files/{id}
```

### Path Parameters

<ParamField path="id" type="string" required>
  The file ID returned when the file was uploaded, e.g., `file_abc123`.
</ParamField>

### Response Body

<ResponseField name="id" type="string">
  The unique file identifier.
</ResponseField>

<ResponseField name="filename" type="string">
  The original filename.
</ResponseField>

<ResponseField name="size_bytes" type="integer">
  The file size in bytes.
</ResponseField>

<ResponseField name="purpose" type="string">
  The purpose assigned at upload time.
</ResponseField>

<ResponseField name="status" type="string">
  The current processing state of the file. One of:
  - `processing` — Piixan AI is indexing the file content
  - `ready` — the file is fully processed and available for use
  - `error` — processing failed; re-upload the file to try again
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp for when the file was uploaded.
</ResponseField>

### Example

```bash cURL
curl https://api.piixan.ai/v1/files/file_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Example response:**

```json
{
  "id": "file_abc123",
  "filename": "document.pdf",
  "size_bytes": 204800,
  "purpose": "context",
  "status": "ready",
  "created_at": "2024-01-15T09:00:00Z"
}
```

## Using a File in a Completion

Once a file's `status` is `ready`, reference it in a completions request by including its ID in the `file_ids` array. Piixan AI will use the file's content as additional context when generating the response.

```bash cURL
curl -X POST https://api.piixan.ai/v1/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "piixan-pro",
    "prompt": "Summarise the key findings in the uploaded report.",
    "file_ids": ["file_abc123"],
    "max_tokens": 512
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.piixan.ai/v1/completions",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json",
    },
    json={
        "model": "piixan-pro",
        "prompt": "Summarise the key findings in the uploaded report.",
        "file_ids": ["file_abc123"],
        "max_tokens": 512,
    },
)

print(response.json()["output"])
```

You can include up to **10 file IDs** per request. Files with `status: processing` cannot be used yet — poll the retrieve endpoint or wait a few seconds before retrying.

<Warning>
  Uploaded files are automatically deleted after **7 days**. If your workflow depends on a file beyond that window, re-upload it and update any stored file IDs. Attempting to use a deleted file ID returns a `404` error.
</Warning>
