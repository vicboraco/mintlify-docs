Piixan AI uses a credit-based billing model so you pay only for what you actually use — there are no per-seat fees or idle charges. You purchase a credit pack, and credits are drawn down as you make API requests. This makes it straightforward to predict costs, allocate budgets across workspaces, and scale usage up or down without negotiating plan changes.

## How Credits Are Calculated

Credits are consumed per API request based on the number of tokens processed — both the tokens in your input (the prompt) and the tokens in the model's output (the completion) count toward usage. The formula is:

```text
credits = (input_tokens + output_tokens) / 1000
```

For example, a request with a 500-token prompt that produces a 300-token completion consumes **0.8 credits**. Because `piixan-pro` is a more capable model, its per-token credit rate is higher than `piixan-1-turbo` — refer to the pricing page at [app.piixan.ai/settings/billing](https://app.piixan.ai/settings/billing) for the per-model rates applied to your plan.

## Checking Your Balance

You can check your current credit balance and monthly usage in two ways: through the dashboard or via the API.

**Dashboard:** Navigate to [app.piixan.ai/settings/billing](https://app.piixan.ai/settings/billing) to see your remaining balance, credits used this billing month, and a request-by-request usage breakdown.

**API:** Send a `GET` request to `https://api.piixan.ai/v1/usage` with your API key. This is useful for building internal dashboards or alerting systems that notify you when your balance runs low.

<CodeGroup>
```bash cURL
curl --request GET \
  --url https://api.piixan.ai/v1/usage \
  --header 'Authorization: Bearer pk_live_abc123xyz'
```

```python Python
import requests

response = requests.get(
    "https://api.piixan.ai/v1/usage",
    headers={"Authorization": "Bearer pk_live_abc123xyz"},
)

print(response.json())
```

```javascript Node.js
const response = await fetch("https://api.piixan.ai/v1/usage", {
  headers: {
    Authorization: "Bearer pk_live_abc123xyz",
  },
});

const data = await response.json();
console.log(data);
```
</CodeGroup>

A successful response looks like this:

```json
{
  "workspace_id": "ws_4fGh8KmNpQrT2vBw",
  "balance": 450.50,
  "used_this_month": 49.50,
  "total_requests_this_month": 1284,
  "plan": "growth",
  "billing_period": {
    "start": "2024-07-01T00:00:00Z",
    "end": "2024-07-31T23:59:59Z"
  }
}
```

| Field | Type | Description |
|---|---|---|
| `workspace_id` | string | Unique identifier of the workspace being queried. |
| `balance` | number | Credits currently available in your workspace. |
| `used_this_month` | number | Credits consumed since the start of the current billing period. |
| `total_requests_this_month` | number | Total number of API requests made this billing period. |
| `plan` | string | Your active plan name. |
| `billing_period.start` | string | ISO 8601 timestamp for the start of the current billing period. |
| `billing_period.end` | string | ISO 8601 timestamp for the end of the current billing period. |

## Credit Tiers

Purchase credits in packs to top up your workspace balance at any time. Larger packs offer a lower effective cost per credit.

| Pack | Credits | Price |
|---|---|---|
| Starter | 500 | $10 |
| Growth | 2,500 | $45 |
| Scale | 10,000 | $160 |
| Enterprise | Custom | Contact us |

To purchase a pack, go to **Settings → Billing** in your workspace dashboard and click **Add Credits**.

<Note>
  Credits do not expire for **12 months** from the date of purchase. Any unused credits remaining after 12 months are forfeited, so plan your pack size based on your expected monthly consumption.
</Note>

<Warning>
  When your workspace credit balance reaches zero, all API requests will fail with a **`402 Payment Required`** response until you top up. Build balance monitoring into your application — poll `GET /v1/usage` and alert your team when `balance` drops below a safe threshold — so you're never caught off guard by a service interruption.
</Warning>
