## How Everything Connects

When you start using Piixan AI, the first thing you do is create a **workspace** — a container that holds your team members, API keys, workflows, and usage data. Inside that workspace, you pick an **AI model** that suits the task at hand: a fast turbo model for high-volume classification jobs, or a pro model for detailed analysis. You then build **workflows** that chain together prompts, transformations, and integrations into reusable pipelines. Every time one of those workflows runs — or whenever you call the API directly — **credits** are deducted from your workspace's balance based on the tokens consumed.

This design keeps things clean: each workspace is independently billed and permissioned, so a staging environment never bleeds into production costs, and a contractor's API key never touches your main project's data.

## Request Lifecycle

Every API call you make travels through the same sequence of steps inside Piixan AI:

<Steps>
  <Step title="API Request">
    Your application sends an HTTPS request to the Piixan AI API (for example, `POST /v1/completions`) with a JSON body describing the task and the model you want to use.
  </Step>
  <Step title="Authentication">
    Piixan AI validates the `Authorization: Bearer <token>` header against your workspace's API keys. Invalid or missing tokens receive a `401 Unauthorized` response immediately.
  </Step>
  <Step title="Model Selection">
    The platform routes your request to the correct model runtime based on the `model` field in your payload. If you omit the field, Piixan AI defaults to `piixan-1`.
  </Step>
  <Step title="Processing">
    The selected model processes your prompt or workflow instructions, applying any configured system context, temperature settings, and token limits you specified.
  </Step>
  <Step title="Response">
    Piixan AI returns a structured JSON response containing the model's output, token usage counts, and a unique request ID you can use for debugging. Credits are deducted from your workspace balance at this point.
  </Step>
</Steps>
